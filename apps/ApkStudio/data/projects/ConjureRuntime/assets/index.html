Tailscale Remote Mesh (tsnet)

📖 Tailscale Setup & Optional Key Guide Tap to Expand ↓

What is Tailscale? Tailscale provides a free, private, end-to-end encrypted connection to access Conjure OS securely from any device in the world (laptop, tablet, or phone) without opening public ports.

Step 1: Enable MagicDNS & HTTPS Certificates

Create an account at Tailscale.com →. Then open Tailscale Admin DNS Settings → and ensure both MagicDNS and HTTPS Certificates are toggled ON.

Step 2: Cross-Device Remote Access

Install the official Tailscale Client App → on your other devices and log into the same account to access Conjure OS using your unique MagicDNS URL.

Step 3: (Optional) Automated Domain Reclaiming Key

An API key (tskey-api-...) or OAuth Secret (tskey-client-...) is completely optional! Entering a key allows Conjure Runtime to automatically purge stale duplicate nodes and reclaim your clean https://conjure..ts.net domain name on launch.
